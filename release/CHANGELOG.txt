A Bit Better Traversal Movement - changelog

1.3.1 (2026-11-26)
- Roll-offs onto the walkable area ([roll] max_drop_walkable=2500): when the floor isn't within max_drop, the roll
  edge checks trace down to max_drop_walkable and ask the game's navigation system (ProjectPointToNavigation on the
  party-sized nav mesh) whether the ground there is walkable; if it is, the roll goes off the edge. Out-of-bounds
  ground has no nav mesh, so it still stops. Tested: reactor platforms (6-25 m, allowed), a 4.7 m grassland cliff
  (allowed), out-of-bounds edges (23-27 m, stopped).
- [traversal] drop_prompt_reach=0.6: when the ledge found leads down (floor ahead more than 60 cm below the feet, or
  none), the ledge search is repeated at 60% of the reach, so jump-down prompts need you closer to the edge.
- Wall stop fixes (players stuck until letting go of the stick): the "blocked without a wall hit" fallback only starts
  while the game's own velocity is high and the character doesn't move, and re-checks every 0.6 s instead of holding
  itself; head-on means within ~60 degrees; movable components (debris, props) never count as walls. The log notes
  each wall stop and why (first 200).
- Game version 1.0.0.4 support (beta; first published as 1.4.0-beta on 2026-11-25). The DLL picks a per-version
  table of game addresses at startup (by the exe's timestamp and size) and finds the game's object table by its structure. Checked on 1.0.0.5 (same behaviour, the
  structure search finds the known address); not yet played on 1.0.0.4.

1.3.0 (2026-11-25)
- Traversal cancel ([transitions] landing_cancel=1): the end of a traversal is ended the game's own way (request code
  in-progress bits cleared, end state 7, traversal bit cleared, "everything allowed" marks set), so control comes back
  instead of waiting for the animation: the dodge / Acrobacias button during a landing rolls or starts the next
  traversal at once; at the end of a vault or climb with the feet on the floor, the button or the stick ends it and
  puts the character back into walking. landing_cancel_move (default 0) also lets the stick end landings.
- The traversal cooldown only holds back automatic traversals; the button is never blocked.
- Ledges found only by the side search (side_angle) never start an automatic vault or drop.
- Wall stop: a push counts as head-on only within ~37 degrees (was ~45), so diagonal pushes slide along walls.
- Rolls: distance_standing=1.6 for rolls from standing still; the stretch follows uphill slopes and only stops after a
  60 cm rise (max_rise; was a fixed 20 cm).

1.2.0 (2026-11-25)
- Wider ledge search: with no ledge straight ahead, the game's own ledge search is asked again with the facing turned
  side_angle degrees (default 35) to each side. 0 = vanilla.
- roll_vault_start=0.15: a roll can still turn into a climb or jump-down in its first 0.15 s, not later.
- Wall stop ignores every character within 40 m (party, NPCs, enemies, animals); before, some party members were missed.
- [transitions] blend / locomotion_blend / blend_min: optional shorter animation blends, default 1 (off).

1.1.0 (2026-11-24)
- New speed groups, each its own [speed] key: climb_wall 1.25, ladder 1.25, rope 1.2 (ropes, poles, zip line
  get-on/off, grappling hook), squeeze 1.3 (narrow gaps, crawl spaces). Rope swings and the zip line ride stay normal.
- Snappier locomotion: run_start 1.2, run_stop 1.25, turn 1.25 (180-degree turns while running, turning on the spot).
  Running and walking loops are unchanged.
- [speed] custom=Prefix:rate,... for any animation family.
- Speeds now also apply to the field-action animations (Motion/FieldAction), for every party member.
- An existing TraversalSpeed.ini keeps your values; the new keys are added on the first start.

1.0.0 (2026-11-24)
- First release: faster traversal, steering in the air and after landing, free landing, landing momentum, longer
  off-combat roll, rolls don't turn into climbs, roll off small ledges, traversal cooldown, closer Acrobacias prompt
  (normal distance in the hands-on-wall pose), wall stop, hands on the wall, camera follows falls.
